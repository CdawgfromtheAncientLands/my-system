The Daring – Core Rules (Web SRD)

This repository contains the web-based System Reference Document (SRD) for The Daring, a tabletop roleplaying game designed and written by Collin Russell for Farrow & Caesar.

The content in /content is transformed and published using the Quartz 4 static site generator. The resulting site provides a fully browsable, searchable rule reference for players, GMs, and third-party creators.

Purpose of This Repository

Provide the complete free rules for The Daring.

Make the core mechanics accessible, hackable, and transparent.

Support community creativity while protecting the commercial future of the system.

Power the official online SRD through Quartz.

The rules in /content will remain free permanently.
Expansions, settings, adventures, and physical books will be published commercially.
